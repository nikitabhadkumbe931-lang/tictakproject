# Tic-Tac-Toe Game (C Language)

## Project Overview
This is a simple two-player Tic-Tac-Toe game developed using the C programming language. The game runs in the console and allows two users to play against each other by taking turns.

## What I Learned From This Project
While building this project, I understood how game logic works in programming and improved my understanding of arrays, loops, and functions in C.

## Features
- Two-player gameplay (X and O)
- Turn-based system
- Win detection (row, column, diagonal)
- Draw detection
- Replay option after each game
- Simple console interface

## How to Run
1. Open terminal in project folder  
2. Compile the code:
   gcc tictactoe.c -o game  
3. Run the program:
   .\game.exe

## Technologies Used
- C Programming Language
- Arrays
- Functions
- Loops
- Conditional Statements
